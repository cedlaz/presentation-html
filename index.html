Structure de Base

Un document HTML commence généralement par la déclaration <!DOCTYPE html> qui indique la version HTML utilisée (par exemple, HTML5).

Ensuite, la structure de base comprend les balises <html>, <head>, et <body> :

<!DOCTYPE html>
<html>
<head>
    <!-- Metadonnées, liens vers des fichiers CSS, etc. -->
</head>
<body>
    <!-- Contenu visible de la page -->
</body>
</html>

Balises HTML

Les balises HTML sont utilisées pour définir la structure et le contenu de la page.

Les balises sont généralement sous la forme <nom_de_la_balise>.

Par exemple, voici une balise de paragraphe :

<p>Ceci est un paragraphe.</p>

Et voici une balise d'image :

<img src="image.jpg" alt="Image de démonstration">

Éléments de Texte

Utilisez des balises pour structurer le texte, par exemple <h1> à <h6> pour les titres de différentes tailles, <p> pour les paragraphes, <em> pour l'italique, <strong> pour le gras, etc.

Voici un exemple de titre :

<h1>Ceci est un titre</h1>

Et voici un exemple de paragraphe en italique :

<p>Ceci est un texte <em>en italique</em>.</p>

Hyperliens

Utilisez la balise <a> pour créer des liens hypertextes vers d'autres pages web ou des ressources.

Voici un exemple de lien vers une page web :

<a href="https://www.example.com">Visitez notre site web</a>

Images

Utilisez la balise <img> pour afficher des images sur votre page. N'oubliez pas d'ajouter l'attribut src pour spécifier le chemin de l'image.

Voici un exemple d'inclusion d'une image :

<img src="image.jpg" alt="Image de démonstration">

Listes

Créez des listes non ordonnées avec <ul> et des listes ordonnées avec <ol>. Utilisez <li> pour chaque élément de la liste.

Voici un exemple de liste non ordonnée :

<ul>
    <li>Élément 1</li>
    <li>Élément 2</li>
    <li>Élément 3</li>
</ul>

Commentaires

Vous pouvez ajouter des commentaires HTML pour expliquer le code. Ils sont délimités par <!-- ... -->.

Voici un exemple de commentaire :

<!-- Ceci est un commentaire expliquant le code -->

Attributs

Les balises peuvent avoir des attributs pour fournir des informations supplémentaires. Par exemple, l'attribut href dans la balise <a> spécifie l'URL de destination.

Voici un exemple d'attribut dans une balise :

<a href="https://www.example.com">Visitez notre site web</a>

Validation

Il est important de veiller à ce que votre code HTML soit valide en utilisant des validateurs en ligne comme le W3C Markup Validation Service.

CSS (Cascading Style Sheets)

Bien que cela ne fasse pas partie intégrante du HTML, la mise en forme de votre page web est souvent gérée par des feuilles de style CSS. Vous pouvez lier une feuille de style externe à votre document HTML pour contrôler la présentation.

Accessibilité

Assurez-vous que votre page est accessible en utilisant des attributs tels que alt pour les images et en respectant les normes d'accessibilité.

Balises Sémantiques

Utilisez des balises sémantiques comme <header>, <nav>, <article>, <section>, etc., pour donner du sens à la structure de votre page et améliorer le référencement.

Pensez à vérifier votre code HTML grâce au validateur HTML du W3C.
